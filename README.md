# Food Company Sales Dashboard 2025

## Project Overview
This project is an interactive Excel-based sales dashboard developed to analyze and visualize the sales performance of a fictional food company, Master Chef Food & Drinks, during 2025.

## Project Objectives
- Analyze yearly sales performance.
- Monitor total cost, sales, profit, and orders.
- Compare monthly profit trends.
- Analyze item-wise sales distribution.
- Compare sales performance across different cities.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Visualization

## Dashboard Features
- Total Cost KPI
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Month-wise Profit Analysis
- Item-wise Sales Analysis
- City-wise Sales Comparison
- Interactive filters for Items, Cities, and Months
